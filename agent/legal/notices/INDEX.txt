Uma Spark Calc capture agent (Uma.Agent.Windows.exe, win-x64) - third-party licences and notices
=================================================================================================

The agent is a self-contained .NET 8 single-file program. Besides its own code it
contains the third-party components listed below. Their licence, copyright and
NOTICE texts are the files in this folder, copied verbatim from the exact package
or upstream source revision named for each component.

Where to find these files
-------------------------
- Release download: the ZIP file contains Uma.Agent.Windows.exe and this LICENSES
  folder. Keep the folder with the EXE when you copy or pass the program on.
- Inside the EXE: the same files are bundled, uncompressed, under legal/. When the
  agent starts, .NET extracts bundled content to
  %TEMP%\.net\Uma.Agent.Windows\<bundle id>\legal\
  (or under DOTNET_BUNDLE_EXTRACT_BASE_DIR if that variable is set).
No network, NuGet or developer tool is needed to read them.
