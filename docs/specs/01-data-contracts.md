# 01 — Data contracts (AUTHORITATIVE)

This file overrides every other spec. Changing it requires an ADR in `docs/adr/` and an orchestrator review.
The contracts live in code in `packages/schema` (zod), are exported to `packages/schema/json/*.schema.json` for the C# agent, and are covered by round-trip tests.

## 1. Identifiers and conventions
- **Master-data IDs** are strings, lower-kebab, stable across versions:
  - `character:<slug>` e.g. `character:mejiro-mcqueen`
  - `outfit:<slug>` e.g. `outfit:frontline-elegance`
  - `skill:<slug>`, `spark:<slug>`, `card:<slug>`, `scenario:<slug>` (e.g. `scenario:ura-finale`, `scenario:unity-cup`)
  - The slug is the English display name, lowercased, with non-alphanumerics collapsed to `-`. Collisions get `-2`, `-3`… and are recorded in `master-data/overrides/ids.json`.
  - A game-internal numeric ID, when the source has one, goes in `gameId` (a number) and is the preferred join key.
- **User-data IDs** are ULIDs (strings).
- Times are ISO-8601 UTC strings. Dates (e.g. Date Acquired) are `YYYY-MM-DD`.
- **Stats** order is always `[speed, stamina, power, guts, wit]`. Keys: `spd, sta, pow, gut, wit`.
- **Aptitude keys**: `turf, dirt, sprint, mile, medium, long, front, pace, late, end`. Grade enum: `G,F,E,D,C,B,A,S` (ordinal 0–7).
- **Rank enum** (veteran overall rank badge): free string validated against master `ranks` (e.g. `A+`, `SS`, `UG`, `UG2`…); master data owns the list.

## 2. Enums
```ts

SparkOwner  = 'self' | 'parent1' | 'parent2'          // parent* = the veteran's parents (child's grandparents)
TrainMode   = 'independent' | 'manual'
ModeSource  = 'epithet' | 'override'
CardType    = 'speed' | 'stamina' | 'power' | 'guts' | 'wit' | 'friend' | 'group'
Rarity      = 'R' | 'SR' | 'SSR'
FieldStatus = 'ok' | 'low_confidence' | 'corrected'
```

## 3. Ingest payload (agent → API)
`POST /api/v1/veterans` with body `VeteranCapture`. The API is **idempotent on `fingerprint`**.

```ts
VeteranCapture = {
  schemaVersion: 1,
  captureId: string,              // ULID, generated by the agent
  capturedAt: string,             // ISO UTC
  agentVersion: string,
  layoutVersion: string,          // e.g. "global-2026-09"
  masterVersion: string,          // master data version used for vocab matching
  fingerprint: string,            // §5
  veteran: {
    characterId: string, outfitId: string,
    rank: string, rating: number, epithet: string,
    trainMode: TrainMode,         // derived by the agent from the epithet (§6)
    stats: { spd: number, sta: number, pow: number, gut: number, wit: number },   // 1..2000
    aptitudes: Record<AptKey, Grade>,
    skills: { skillId: string, level: number | null }[],   // level only for unique skills
    sparks: { owner: SparkOwner, sparkId: string, type: SparkType, stars: 1|2|3 }[],
    deck: { slot: 1..6, cardId: string, lb: 0..4, level: number, borrowed: boolean }[],  // exactly 6
    parents: { slot: 1|2, characterId: string, outfitId: string | null,
               isGuest: boolean, guestTrainer: string | null }[],   // exactly 2
    scenarioId: string,
    career: { races: number, wins: number, fans: number | null, dateAcquired: string }
  },
  fields: CaptureField[]          // one per extracted field: provenance + confidence
}

CaptureField = {
  path: string,                   // JSON pointer into `veteran`, e.g. "/stats/spd", "/sparks/3/stars"
  rawText: string | null,
  value: unknown,
  confidence: number,             // 0..1
  status: FieldStatus,
  candidates: { value: unknown, score: number }[],   // top 3, for text matched to vocab
  cropKey: string | null          // R2 key if a crop was uploaded (§8)
}
```
**Validation (API rejects with 422, and the agent validates the same rules before upload):**
- The 5 stats are integers 1–2000. There are exactly 10 aptitudes, 6 deck slots and 2 parents.
- `self` sparks: exactly one blue and one pink; at most one green; any number of white.
- The same shape holds for each `parent*` owner that has sparks. The owner may have none if the tab couldn't be read, in which case a field is flagged `low_confidence`.
- Parents: `parents[0].characterId != parents[1].characterId`. Both differ from `veteran.characterId`.
- Every ID exists in the master data version named by `masterVersion`.

**Response:** `201 {veteranId, created: true}` or `200 {veteranId, created: false}` (same fingerprint, fields updated). If any field is `low_confidence`, the response adds `reviewItemIds: string[]`.

## 4. Support card sync
`PUT /api/v1/owned-cards` with body:
```ts
OwnedCardsSync = { schemaVersion: 1, capturedAt: string, masterVersion: string,
                   heldCount: number,                        // from "Held N/255"
                   cards: { cardId: string, lb: 0..4, level: number, confidence: number }[] }
```
The API replaces the table atomically. It rejects the sync if `cards.length != heldCount`, unless `?partial=1` is set.

## 5. Fingerprint
`sha256` hex of the UTF-8 canonical JSON of:
```
{ c: characterId, o: outfitId, s: [spd,sta,pow,gut,wit], a: [10 grades in key order],
  sp: sorted("owner|sparkId|stars") of all sparks, p: [parent1.characterId, parent2.characterId],
  d: dateAcquired }
```
Canonical JSON means keys sorted, no whitespace. A reference implementation lives in `packages/schema/src/fingerprint.ts`. The C# agent **must** produce identical output: `packages/schema/test/fingerprint.vectors.json` holds ≥ 5 vectors that both test suites run.

## 6. Train-mode rule
`trainMode = epithet.trim().toLowerCase() === 'independent learner' ? 'independent' : 'manual'`, with `modeSource = 'epithet'`. A user override (API `PATCH /api/v1/veterans/:id {trainMode}`) sets `modeSource = 'override'`. Later captures never overwrite an override.

## 7. D1 schema (user data)
Migrations in `apps/api/migrations/NNNN_*.sql`. SQLite types. All tables are `STRICT`.
```sql
veterans(id TEXT PK, fingerprint TEXT UNIQUE NOT NULL, character_id TEXT NOT NULL, outfit_id TEXT NOT NULL,
  rank TEXT, rating INTEGER, epithet TEXT, train_mode TEXT NOT NULL, mode_source TEXT NOT NULL,
  spd INTEGER, sta INTEGER, pow INTEGER, gut INTEGER, wit INTEGER,
  apt_turf TEXT, apt_dirt TEXT, apt_sprint TEXT, apt_mile TEXT, apt_medium TEXT, apt_long TEXT,
  apt_front TEXT, apt_pace TEXT, apt_late TEXT, apt_end TEXT,
  scenario_id TEXT NOT NULL, races INTEGER, wins INTEGER, fans INTEGER, date_acquired TEXT,
  master_version TEXT NOT NULL, capture_id TEXT NOT NULL, captured_at TEXT NOT NULL,
  min_confidence REAL NOT NULL, created_at TEXT NOT NULL, updated_at TEXT NOT NULL)
veteran_skills(veteran_id TEXT, skill_id TEXT, level INTEGER, PRIMARY KEY(veteran_id, skill_id))
veteran_sparks(veteran_id TEXT, owner TEXT, spark_id TEXT, type TEXT, stars INTEGER,
  PRIMARY KEY(veteran_id, owner, spark_id))
veteran_deck(veteran_id TEXT, slot INTEGER, card_id TEXT, lb INTEGER, level INTEGER, borrowed INTEGER,
  PRIMARY KEY(veteran_id, slot))
veteran_parents(veteran_id TEXT, slot INTEGER, character_id TEXT, outfit_id TEXT, is_guest INTEGER,
  guest_trainer TEXT, matched_veteran_id TEXT NULL, PRIMARY KEY(veteran_id, slot))
capture_fields(veteran_id TEXT, path TEXT, raw_text TEXT, value_json TEXT, confidence REAL, status TEXT,
  candidates_json TEXT, crop_key TEXT, PRIMARY KEY(veteran_id, path))
review_items(id TEXT PK, veteran_id TEXT, path TEXT, status TEXT CHECK(status IN('open','resolved','dismissed')),
  resolved_value_json TEXT, created_at TEXT, resolved_at TEXT)
owned_cards(card_id TEXT PK, lb INTEGER, level INTEGER, confidence REAL, synced_at TEXT)
cm_targets(id TEXT PK, name TEXT, body_json TEXT NOT NULL, created_at TEXT, updated_at TEXT)

```
Indexes: `veterans(character_id)`, `veterans(train_mode, scenario_id)`, `veteran_sparks(spark_id)`, `review_items(status)`.

## 8. R2 keys
`crops/<veteranId or captureId>/<urlencoded path>.png`, PNG, at most 60 KB each. Upload: `PUT /api/v1/crops/:captureId?path=…` (raw body) returns `{cropKey}`. Download: `GET /api/v1/crops/:key`.

## 9. Read API (web)
| Method | Path | Returns |
|---|---|---|
| GET | `/api/v1/roster` | `RosterVeteran[]`: full veterans with skills, sparks (all owners), deck, parents. Supports ETag / `If-None-Match`. |
| GET | `/api/v1/veterans/:id` | `RosterVeteran` + `fields` |
| PATCH | `/api/v1/veterans/:id` | `{trainMode?}` → updated |
| DELETE | `/api/v1/veterans/:id` | 204 |
| GET | `/api/v1/review-items?status=open` | `ReviewItem[]` joined with field + crop key |
| POST | `/api/v1/review-items/:id/resolve` | `{value}` → applies to the veteran, recomputes the fingerprint (409 if it collides), status `resolved` |
| GET/PUT | `/api/v1/owned-cards` | list / sync (§4) |
| GET/POST/PUT/DELETE | `/api/v1/cm-targets[/:id]` | `CmTarget` |
| GET/POST | `/api/v1/model-snapshots[?kind=]` | latest snapshot / store one (from the web worker) |
| GET | `/api/v1/health` | `{ok, masterVersion, dbSchemaVersion}` (unauthenticated) |

`RosterVeteran` = the `veteran` object from §3 + `{id, fingerprint, modeSource, minConfidence, capturedAt}` + `parents[].matchedVeteranId`.

## 11. Master data bundle (static JSON)
Path: `/master/<masterVersion>/` with an index `/master/latest.json` → `{version, files:{…}, sha256:{…}}`.
| File | Shape |
|---|---|
| `characters.json` | `{id, gameId?, name, aliases[], affinityGroups: string[], iconHashes: string[] /*dHash hex of portrait icons, for parent/grandparent ID*/}` |
| `outfits.json` | `{id, gameId?, characterId, title, aptitudes: Record<AptKey,Grade>, growth: Record<StatKey, number /*percent*/>, uniqueSkillId, innateSkillIds[]}` |
| `skills.json` | `{id, gameId?, name, aliases[], rarity:'normal'|'gold'|'unique'|'evolved', cost?: number, tags[]}` |
| `sparks.json` | `{id, gameId?, name, type: SparkType, target: {kind:'stat',stat}|{kind:'aptitude',apt}|{kind:'skill',skillId}|{kind:'race',raceId}|{kind:'scenario',scenarioId}}` |
| `cards.json` | `{id, gameId?, name, title, characterId?, type: CardType, rarity: Rarity, hintSkillIds[], eventSkillIds[], artHashes: string[] /*dHash hex*/}` |
| `affinity.json` | `{groups: {id, members: characterId[], points: number}[]}`, or the pairwise table the source provides; the engine uses `affinity(a,b)` and `affinity(a,b,c)` |
| `scenarios.json` | `{id, name, statCap, inheritanceTurns: number[], extra?: object}` |
| `ranks.json` | `{id, minRating}` |
| `vocab.json` | Flat list for OCR matching: `{kind:'character'|'outfit'|'skill'|'spark'|'scenario'|'epithet', id, text}` |
| `rules.json` | Inheritance constants, **each with `verified` and `source`** (§12) |

## 12. Inheritance rules file
```jsonc
{
  "version": "rules-1",
  "activation": {                         // chance per inheritance event, before affinity
    "blue":  {"1": x, "2": x, "3": x, "verified": false, "source": "…"},
    "pink":  {…}, "green": {…}, "white": {…}
  },
  "affinityMultiplier": {"formula": "1 + affinity/100", "verified": false, "source": "…"},
  "grandparentWeight": {"value": x, "verified": false, "source": "…"},  // if the source says grandparents roll with lower odds
  "blueStatGain": {"1": x, "2": x, "3": x, …},        // per activation
  "blueInitialBonus": {"1": x, "2": x, "3": x, …},    // at career start, parents only
  "pinkGradeGain": {"1": 1, "2": 1, "3": 1, …},
  "whiteHintLevels": {"1": x, "2": x, "3": x, …},
  "raceSparkStatGain": {…}, "scenarioSparkEffects": {…}
}
```
Every number an agent can't verify from a cited source stays `verified:false`. The engine must run with any values; nothing is hard-coded in engine code.
