## Decisions
- **Data access:** GameTora exposes `https://gametora.com/data/manifests/umamusume.json` (key → hash) and `…/data/umamusume/<key>.<hash>.json`; no HTML parsing needed.
- **Global filters:** characters `playable_en`; outfits `release_en` (107, matching 68 characters); support cards `release_en`; skills have an English name and aren't `unreleased:["en"]`; scenarios have `start_en`; JP-only content is excluded. Global copies of the `db-files` tables are used (`en/…`).
- **Names:** Global names come from `name_en_gl`/`title_en_gl`; the `skills` file's `name_en` is the Global skill name (its `enname` is the JP-translated one).
- **◯ vs ○:** GameTora uses U+25CB; the spec uses U+25EF. Skill names are canonicalised to ◯; `vocab.json` contains both glyphs. ◎ variants are separate skills.
- **dHash:** integer-only, so TS and C# cannot drift: permille crop → alpha flatten over white → BT.601 luma ×1000 → area-average 9×8 with integer cell edges → compare by cross-multiplication → row-major MSB-first hex (16 chars). Full text in `src/dhash.ts`; 11 vectors generated by independent Python and asserted in vitest. Bump `DHASH_VERSION` if the definition changes.
- **Hash sources:** character icons: round icon `chr_icon_<charId>.png` plus each outfit's `veteran_icon/<cardId>_01.png` (2–4 hashes per character); cards: full portrait `tex_support_card_<id>.png` (review round 1). Images never touch the repo (only hashes are in `.cache/hashes.json`, gitignored).
- **Outfit ID:** slug of the bracket-less Global title (`Frontline Elegance` → `outfit:frontline-elegance`); collisions get `-2`… and every colliding entry is pinned in `overrides/ids.json` for stability. Card IDs are `card:<title>-<character>`.
- **Unique skill of an outfit:** the last released id in `skills_unique` (the ☆-upgraded one); green spark target is the skill whose name equals the Global green factor name.
- **Affinity:** groups = one `relation_type` each (`relation:<type>`) with its `relation_point`; members restricted to Global characters; one-member groups dropped. This is the same data GameTora's calculator sums (pair affinity = sum of shared groups).
- **`rules.json`:** copy-rate table and `1 + affinity/100` taken from GameTora's calculator code, blue initial bonus 5/12/21 from its article, all `verified:false` with URLs. Unknown values (`blueStatGain`, `whiteHintLevels`) are `0` and say `UNKNOWN`.
- **Build determinism:** stable sort by id, 2-space JSON, LF. Verified by building twice offline and `diff -r` (identical).
- **Tests read the committed bundle** (`apps/web/public/master/latest.json`), so they check the shipped artefact, not a fixture.
- **Lint scope:** the package `lint` script excludes the gitignored `.cache/` (it holds downloaded GameTora JS and made ESLint report 2,768 errors).
