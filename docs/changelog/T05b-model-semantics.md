## Summary

ADR-0002 defines the training-model semantics T06 must implement:

- **Q-123 (residual covariance).** The covariance is the non-inheritance Σ_N, estimated by out-of-fold (OOF) deconvolution with exact weighting, uncentring, same-weighted C̄ subtraction and deterministic Jacobi PSD flooring. Inheritance is added once at prediction.
- **Q-124 (skill acquisition).** Acquisition uses an exposure-aware likelihood. The non-conjugate posterior is computed by deterministic tanh-sinh quadrature and stored as a moment-matched Beta in the existing `{a, b}` shape.

Both are independently reproduced by retained, seeded, byte-deterministic code under `docs/reference/model-semantics/`. I did not rely on the adviser's deleted probes.

`ModelSnapshot.kind` is now the enum `training-v1 | training-v2`:

- v1 is legacy. It is still accepted, stored and read unchanged, and never relabelled.
- The API `Row.kind` is derived from the schema.
- Per-kind filtering and pruning are isolated and tested.
- Explicit errata were applied to 01 §13, 50 §4/§5/§7/§8/§9 and 70 §3.

## Decisions

**Q-123: covariance (ADR-0002 §2)**

- The adviser's estimator B is adopted only after reproducing it in TS.
- Every step is specified exactly:
  - one recency clock (the newest train row);
  - the CV fold partition, with λ fixed at the CV choice;
  - an uncentred second moment, with no degrees-of-freedom correction;
  - C̄ computed with the same weights as S;
  - sym → Jacobi with tol 1e-12·‖R‖_F and ≤ 100 sweeps (typed error beyond that), ascending eigenvalues, a sign convention, and ε = 1e-6·max(1, tr S/5);
  - an all-zero input gives εI.
- A diag(S − C̄) ≤ 0 warning is emitted.
- I did not add an inflation constant.

**Q-124: skill acquisition (ADR-0002 §3)**

- The exposure-aware likelihood is chosen over the conservative q = 1-only fit. Both are equally reliable on the golden holdout, but the conservative fit discards 1,867 lineage cells and leaves 142/124 skills at the prior.
- The adviser's "drop the extra Bernoulli" is rejected with evidence: on lineage-only holdout cells it predicts 128.9 acquisitions against 57 observed (z −7.8).
- q < 1 successes are an exact a += 1, because q cancels. q < 1 failures make the posterior non-conjugate; it is integrated by quadrature. Nothing is labelled as fractional or conjugate counting.
- The moment-matched Beta keeps the 01 §13 `{a, b}` shape; prediction uses only the mean.
- The global prior is an exposure-aware method of moments on train rows. Its numerical guards (m in [0.005, 0.995], ν in [2, 1000]) bind on neither mode of the golden data: ν is 12.85 (independent) and 9.79 (manual).

**Versioning**

- One `training-v2` kind carries both meanings together.
- v1 is legacy/unknown and never reinterpreted.
- I did not implement the T06 runtime guard; its required acceptance is written into 50 §9 and ADR-0002 §4.

**Evidence tooling**

- The evidence code runs with Node's native type stripping and `node:test`, so it needs no new dependency and no workspace wiring.
- Typecheck and lint run against the repo base config and the root ESLint config.
- Result JSON is written through the repo's pinned Prettier, so reruns give the same sha256.

## Open questions / follow-ups

- **Q-123, Q-124:** proposed resolutions recorded. Pending independent review; the orchestrator transitions them.
- **Q-130 (new):** q = 1 for deck hint/event or innate skills is an unverified approximation.
- **Q-131 (new):** acquired skills with no observable source (q = 0) are excluded and reported. The golden data has none; the real roster may.
- **T06 handoff:**
  - Implement ADR-0002 §2/§3 in `packages/engine/src/`.
  - Emit only `training-v2`; throw a typed refit-required error for `training-v1`.
  - Use separate `${seed}:inh` / `${seed}:train` streams.
  - Sample availability once.
  - Write the 50 §9 tests 1–7.
  - Card recovery uses the Q-122 estimand: the effective contribution β_id[card] + β_type[type(card)] per unit of (1 + lb/4), every planted card and stat within ±15%. The β_id/β_type split itself is penalty-determined and not tested.
- **T07/T13:** the σ column label should read "training σ (excl. inheritance)" for v2, and S07 should show v1 snapshots as legacy/refit required.
- **Known limitations** (ADR-0002 §2/§3):
  - Additivity, and Var[inh] correctness under unverified rules, are assumptions; the golden inheritance is SYNTHETIC (Q-120).
  - A finite-sample under-coverage of about 0.01–0.02 remains across splits, and about 1 in 40 random splits falls below 0.72. No inflation is applied.
  - Fold reuse for λ and OOF is mildly optimistic and not quantified.
  - The golden best/trap test does not discriminate between skill estimators.
  - The global prior's single-Beta-population assumption is unverified.
