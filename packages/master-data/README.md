# @uma/master-data

Builds the static Global-server master data bundle (`apps/web/public/master/<version>/*.json`, shapes in `docs/specs/01-data-contracts.md` §11).

Data credit: **GameTora** (https://gametora.com/umamusume). Game materials © Cygames, Inc.; this project is not affiliated. See `SOURCES.md`.

```
pnpm --filter @uma/master-data build                    # fetch (cached, 1 req/s) -> normalise -> hash images -> validate -> write
pnpm --filter @uma/master-data build -- --offline       # cache only
pnpm --filter @uma/master-data build -- --no-images     # skip dHash step
pnpm --filter @uma/master-data build -- --date 20260930 # version = global-<date>[-N]
```
- `src/dhash.ts` is the normative 64-bit dHash definition (the C# agent must reproduce it); vectors in `test/dhash.vectors.json`, generated by the independent `scripts/dhash_ref.py`.
- `src/art-crop.ts` holds the crop boxes mirrored by `agent/layouts/*.json`.
- `overrides/ids.json` pins slug-collision IDs (auto-written); `overrides/aliases.json` adds in-game spelling aliases.
- Images are decoded in memory (sharp) and never written to disk; only hashes are stored.
